# WEconnect Email Assets

Public image assets for WEconnect Health marketing emails, served via the
jsDelivr CDN so they load reliably in inboxes.

Base URL: `https://cdn.jsdelivr.net/gh/spencermoser/weconnect-email-assets@main/`

| File | Use |
|---|---|
| `wordmark-color.png` | Header + footer logo |
| `app-home.png` | Hero app screenshot |
| `founders-award.jpg` | Founders story photo |
| `badge-appstore.png` | App Store badge |
| `badge-googleplay.png` | Google Play badge |

Optimized for email (total ~660KB). Managed from the WEconnect Email Studio.
